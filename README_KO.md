# ChatGPT Ctrl+Enter 및 브라우저 도구 1.29.0

## 버전 1.29.0 안전성 및 복원 수정

- 사용자가 실제로 누른 마우스와 키보드 입력에만 새 탭 열기, ChatGPT 전송, 미디어 단축키, 영역 캡처 및 요소 숨기기가 반응합니다. 웹페이지가 `dispatchEvent()`로 만든 입력에는 반응하지 않습니다.
- 뒤로 가기 보호와 외부 링크 경고 건너뛰기의 설정 전달에 문서 속성이나 사용자 정의 이벤트를 사용하지 않습니다. 서비스 워커가 해당 프레임의 페이지 실행 환경에 설정값을 직접 전달합니다.
- 자바스크립트 버튼의 주소는 클릭한 명시적 조작 요소의 `data-href`, `data-url`, `data-link-url`, `data-target-url` 또는 문자열 리터럴 형태의 `window.open()`과 `location` 이동 코드에서만 확인합니다. 주소가 확실하지 않으면 아무 동작도 하지 않습니다.
- 우클릭 메뉴의 **링크 주소 복사**는 Chrome이 제공한 일반 링크 주소를 우선하며, 경유 주소의 매개변수를 최종 주소라고 추정하여 풀지 않습니다.
- 뒤로 가기 방해 차단은 실제 `popstate` 직후의 짧은 시간에 같은 주소를 다시 추가하거나 앞으로 되돌리는 동작만 막습니다. 일반적인 단일 페이지 응용 프로그램의 평상시 `pushState()`는 건드리지 않습니다.
- 유튜브 자막 추출이 끝나면 성공 여부와 관계없이 기존 자막 트랙, 자막 표시 상태, HTML5 텍스트 트랙 모드, 확장 프로그램이 연 자막 패널과 펼친 설명 영역을 가능한 범위에서 원래 상태로 되돌립니다.
- 미디어 소스별 임시 상태에는 서명과 토큰이 포함된 전체 미디어 주소를 저장하지 않고 불투명한 해시 식별자만 저장합니다. 이전 버전의 주소 기반 세션 상태는 업데이트 과정에서 즉시 삭제합니다.
- 사이트에 기억하는 요소 숨기기는 위치 순서에 의존하는 `:nth-of-type()` 선택자와 클래스만으로 된 선택자를 저장하지 않습니다. 고유하고 안정적인 식별자나 속성으로 안전하게 다시 찾을 수 없는 요소는 저장하지 않고 이번 페이지에서만 숨기도록 안내합니다. 이전 버전에서 저장된 불안정한 규칙은 업데이트할 때 삭제합니다.

## 버전 1.28.0 자막 수정

- 버전 1.27.0에서 `HTTP 400 · Precondition check failed`를 일으킨 내부 자막 API 조립 코드를 완전히 제거했습니다.
- 확장 프로그램이 `youtubei/v1/get_transcript`의 매개변수나 인증 헤더를 임의로 만들지 않습니다.
- 먼저 현재 자막 트랙의 기존 주소를 읽고, 그 주소가 비어 있으면 유튜브 플레이어가 실제로 발급한 자막 요청과 응답을 잠시 포착합니다.
- 플레이어 요청에는 유튜브가 발급한 서명과 재생 증명 토큰이 들어 있으므로 그 값을 수정하지 않고 그대로 사용합니다.
- 플레이어 요청을 얻지 못한 경우에는 유튜브의 자막 패널이 실제로 보낸 응답과 패널에 표시된 자막 문장을 차례로 확인합니다.
- 단일 탭과 여러 탭의 복사 및 저장 기능이 모두 같은 추출 경로를 사용합니다.


이 확장 프로그램은 ChatGPT의 두 가지 입력란에서 `Ctrl + Enter`로 메시지를 전송하고 대화 기록과 새 메시지 입력란의 너비를 각각 조절합니다. 또한 현재 창에 열린 유튜브 일반 영상과 Shorts 탭을 골라 전체 자막을 한꺼번에 복사하거나 텍스트 파일로 저장하고, 각 탭의 HTML5 동영상과 오디오 재생 속도를 서로 독립적으로 제어합니다. 화면 캡처와 페이지 요소 숨기기, 열린 탭 URL 복사, 웹페이지 입력 제한 해제 및 사이트 자체 외부 링크 경고 건너뛰기 기능도 제공합니다.

## 설치 및 업데이트 방법

1. ZIP 파일의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. 새로 설치할 때에는 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 압축을 풀어서 생긴 `chatgpt_ctrl_enter_extension` 폴더를 선택합니다.
6. 기존 버전의 파일을 덮어쓴 경우에는 확장 프로그램 카드의 **새로고침** 버튼을 누릅니다.
7. 이미 열려 있던 ChatGPT 탭과 미디어 속도 조절 또는 웹페이지 제한 해제 기능을 사용할 탭도 한 번 새로 고칩니다.
8. 로컬 동영상과 오디오 파일에도 적용하려면 확장 프로그램의 **세부정보**에서 **파일 URL에 대한 액세스 허용**을 켭니다.

버전 1.17.0에서는 정상적인 링크를 확장 프로그램이 대신 여는 처리와 수동 방문 색상 표시를 제거했습니다. 업데이트한 뒤 웹페이지를 새로 고치면 이전 버전이 넣었던 방문 색상용 표시도 정리되며, 예전 방문 색상 저장 기록은 확장 프로그램 업데이트 과정에서 삭제됩니다.

버전 1.12.0에서 업데이트하면 **버튼 링크를 새 탭에서 열기**와 **링크 주소 복사** 우클릭 메뉴를 만들기 위해 `contextMenus` 권한이 새로 추가됩니다. Chrome에서 권한 확인 화면이 나타나면 승인해 주세요. 기존에 **텍스트 드래그 및 선택 허용**을 켜 두었다면, 이전 버전의 복사 동작을 유지하도록 **복사 차단 및 문구 변경 방지**도 계속 켜진 상태로 유지됩니다.

버전 1.19.0에서는 작은 Chrome 도구 모음에서도 알아보기 쉽도록 글자 기반 아이콘을 없애고, 굵은 마우스 포인터와 클릭 표시를 사용한 새 아이콘으로 교체했습니다. 또한 웹페이지 입력 제한 해제 기능 열 가지를 한 번에 켜거나 끌 수 있는 상위 토글을 추가했습니다.

버전 1.20.0에서는 패널에 **ChatGPT 대화 너비** 슬라이더를 추가했습니다. 버전 1.21.0에서는 대화 기록의 최대 너비를 2,000픽셀로 늘리고, 화면 하단의 새 메시지 입력란도 별도의 슬라이더로 2,000픽셀까지 조절할 수 있게 했습니다. 기존 대화 너비 설정값은 그대로 유지되며, 새 입력란 너비는 처음에는 ChatGPT 기본 너비를 사용합니다.

버전 1.22.0에서는 표준 HTML5 동영상과 오디오의 재생 속도를 0.07배속부터 16배속까지 설정하는 기능을 추가했습니다. 영상 위 속도 표시창, 표시창 위치 이동, 속도 변경 간격과 앞뒤 이동 간격 설정 및 키보드 조작도 함께 추가했습니다. 기존 설치에서 미디어 속도가 갑자기 바뀌지 않도록 이 기능은 처음에는 꺼져 있습니다.

버전 1.23.0에서는 속도 표시창의 기본 위치를 영상 가운데 위로 옮겼습니다. 새 동영상이나 오디오에 마지막 배속을 이어서 적용할지 선택하는 설정을 추가했으며, 이 설정을 끄면 새 미디어는 1.00배속으로 시작합니다. `R` 키는 1.00배속과 직전에 사용한 배속을 서로 전환하며, 여섯 가지 미디어 단축키를 패널에서 각각 다른 키로 지정할 수 있습니다.

버전 1.24.0에서는 이전 배속 기록이 없는 미디어에서 `R` 키를 눌렀을 때 사용할 **기본 복원 배속**을 추가했습니다. 초기값은 2.00배속이며 패널에서 0.07배속부터 16배속까지 설정할 수 있습니다. 미디어가 일시적으로 잘못된 0 값을 보고할 때 이를 0.07배속으로 기억하던 문제도 함께 막았습니다.

버전 1.25.0에서는 유튜브 일반 영상과 Shorts에서 현재 영상의 전체 자막을 불러와 클립보드에 복사하거나 UTF-8 텍스트 파일로 저장하는 기능을 추가했습니다. 원본 자막 트랙과 유튜브가 제공하는 자동 번역 언어를 선택할 수 있으며, 영상 제목과 재생 시간의 포함 여부 및 자막 줄 사이의 빈 줄 개수를 설정할 수 있습니다.

버전 1.26.0에서는 미디어 재생 속도를 탭별이면서 미디어 소스별로 분리했습니다. 한 탭의 배속 변경은 다른 탭에 전달되지 않으며, 같은 탭에 여러 동영상이나 오디오가 있어도 현재 재생 중이거나 마지막으로 마우스를 올린 소스 하나만 바뀝니다. 같은 플레이어가 이전 소스로 돌아오면 그 소스에서 사용하던 배속을 다시 적용합니다. 유튜브 자막 영역에는 현재 Chrome 창에 열린 영상과 Shorts 탭 목록을 추가했으며, 여러 탭을 선택하여 자막을 하나의 클립보드 또는 하나의 텍스트 파일로 합치거나, 탭별 개별 텍스트 파일로 일괄 저장할 수 있습니다. 각 탭의 원본 자막과 자동 번역 언어도 따로 선택할 수 있습니다.

버전 1.28.0에서는 유튜브가 일부 자막 주소에 재생 증명 토큰을 요구하면서 빈 본문을 반환하는 경우를 처리하도록 추출 방식을 수정했습니다. 확장 프로그램이 내부 자막 API 요청을 추측하여 조립하지 않고, 유튜브 플레이어가 선택한 자막을 실제로 불러올 때 발급한 요청을 포착하여 사용합니다. 해당 요청을 얻지 못한 경우에만 유튜브 자막 패널의 실제 응답과 화면에 표시된 자막 문장을 차례로 확인합니다. 단일 탭과 여러 탭 작업은 같은 수정된 추출 경로를 사용합니다.


## ChatGPT 단축키

패널에서 다음 두 기능을 각각 켜거나 끌 수 있습니다.

- 화면 하단의 새 메시지 입력란에서 `Ctrl + Enter`로 전송
- 연필 모양 버튼으로 연 이전 메시지 편집란에서 `Ctrl + Enter`로 전송

한글과 같은 문자를 조합하는 도중에는 메시지를 전송하지 않습니다.

## ChatGPT 대화와 입력란 너비

패널의 **ChatGPT 너비** 영역에는 두 개의 슬라이더가 있습니다.

### 대화 기록 너비

사용자 메시지와 GPT 답변이 배치되는 대화 기록의 너비를 조절합니다.

- 기존 설치의 설정값은 그대로 유지됩니다.
- 처음 사용하는 너비는 960픽셀입니다.
- 슬라이더의 왼쪽 끝은 확장 프로그램의 너비 지정을 제거하여 ChatGPT의 기본 너비를 사용합니다.
- 그다음부터 640픽셀에서 2,000픽셀까지 40픽셀 간격으로 조절할 수 있습니다.

### 새 메시지 입력란 너비

화면 하단에서 새 메시지를 작성하는 입력란과 그 바깥 작성 영역의 너비를 조절합니다.

- 처음에는 ChatGPT의 기본 입력란 너비를 사용합니다.
- 슬라이더의 왼쪽 끝은 확장 프로그램의 입력란 너비 지정을 완전히 제거합니다.
- 그다음부터 640픽셀에서 2,000픽셀까지 40픽셀 간격으로 조절할 수 있습니다.
- 이전 메시지를 수정할 때 나타나는 메시지 내부 편집란은 이 슬라이더의 대상이 아닙니다.

두 너비 모두 브라우저 창이 설정값보다 좁으면 현재 화면 안에 들어오도록 자동으로 제한됩니다. 변경 내용은 이미 열려 있는 ChatGPT 탭에 즉시 적용되고 Chrome 저장소에 보관됩니다.

이 기능은 문서 구조를 반복해서 검사하거나 변경 감시 기능을 사용하지 않습니다. 대화 기록과 입력란에 적용되는 작은 스타일 규칙만 갱신하므로, 새 메시지가 추가되거나 입력란이 다시 그려져도 별도의 반복 작업 없이 같은 너비가 유지됩니다.


## 유튜브 전체 자막

패널의 **유튜브 전체 자막**을 펼치면 현재 Chrome 창에 열린 일반 유튜브 영상, Shorts 및 라이브 영상 탭이 탭 표시 순서대로 나타납니다.

1. 자막을 처리할 탭을 체크합니다. **모두 선택**, **선택 해제** 및 **새로고침**을 사용할 수 있습니다.
2. 선택한 각 탭에서 **원본 자막**을 고릅니다. 자동 생성 자막은 목록에 따로 표시됩니다.
3. 필요한 탭에서는 **유튜브 자동 번역** 언어를 선택합니다. 자동 번역을 지원하지 않는 자막 트랙은 원본 자막만 사용할 수 있습니다.
4. **영상 제목 포함**, **재생 시간 포함** 및 **자막 줄 사이의 빈 줄**을 원하는 형태로 설정합니다.
5. 다음 세 가지 작업 중 하나를 실행합니다.
   - **선택 자막 모두 복사**: 선택한 탭의 자막을 탭 순서대로 하나의 클립보드 내용으로 합칩니다.
   - **한 파일로 저장**: 선택한 자막 전체를 하나의 UTF-8 텍스트 파일로 저장합니다.
   - **개별 파일 일괄 저장**: 두 개 이상의 탭을 선택했을 때 각 영상의 자막을 별도 텍스트 파일로 저장합니다.

합친 텍스트에서는 영상 하나가 끝날 때마다 빈 줄을 추가하여 다음 영상과 구분합니다. **영상 제목 포함**을 켜면 각 영상의 제목이 해당 자막 앞에 들어갑니다. 제목을 끄면 별도의 영상 구분 제목을 임의로 추가하지 않습니다.

재생 시간은 `[MM:SS]` 형식으로 표시하며 한 시간이 넘는 영상은 `[HH:MM:SS]` 형식을 사용합니다. 자막 데이터 안의 불필요한 공백과 줄바꿈은 문장별 한 줄 텍스트로 정리합니다.

하나의 파일로 저장한 결과는 다음 폴더에 들어갑니다.

```text
다운로드\youtube_transcripts
```

여러 개의 개별 파일은 작업 시각별 하위 폴더에 탭 표시 순서대로 번호를 붙여 저장합니다.

```text
다운로드\youtube_transcripts\batch_YYYYMMDD_HHMMSS
```

한 탭에서 자막을 가져오지 못해도 성공한 탭의 작업은 계속합니다. 실패한 탭에는 목록 안에 오류 원인이 표시되며, 완료 메시지에는 성공한 탭과 건너뛴 탭의 개수가 함께 나타납니다.

자막 추출을 위해 일시적으로 자막 트랙을 켜거나 자막 패널을 연 경우에는 작업이 끝난 뒤 기존 트랙, 자막 표시 상태, 텍스트 트랙 모드, 패널과 설명 영역을 원래 상태로 되돌립니다.

이 기능은 외부 자막 서비스나 별도 계정 연동을 사용하지 않습니다. 사용자가 작업 버튼을 누를 때 선택한 각 유튜브 탭의 플레이어가 제공하는 자막 트랙과 자동 번역 언어를 읽습니다. 자막이 없는 영상, 절전 상태에서 플레이어 정보가 내려간 탭 또는 유튜브가 자막 데이터를 제한한 영상은 건너뛸 수 있습니다.

## 동영상 및 오디오 재생 속도

패널에서 **동영상 및 오디오 재생 속도**를 펼친 뒤 **HTML5 미디어 속도 조절**을 켭니다. 기존 설치의 재생 상태를 갑자기 바꾸지 않도록 처음에는 꺼져 있습니다.

### 재생 속도

- 현재 재생 중이거나 마지막으로 마우스를 올린 `<video>` 또는 `<audio>` 소스 하나만 조절합니다. 같은 탭의 다른 미디어와 다른 탭의 속도에는 영향을 주지 않습니다.
- 0.07배속부터 16배속까지 0.01배 단위로 직접 입력하거나 슬라이더로 조절할 수 있습니다.
- **새 미디어에 마지막 속도 유지**를 켜면 아직 별도 배속 기록이 없는 새 동영상, 새 오디오 또는 새 소스에 현재 탭에서 마지막으로 설정한 배속을 적용합니다.
- 이 설정을 끄면 새 동영상과 오디오는 1.00배속으로 시작합니다. 버전 1.23.0에서 새로 추가된 설정은 처음에는 꺼져 있습니다.
- 유튜브처럼 페이지를 새로 열지 않고 플레이어를 교체하는 사이트에서도 미디어 요소와 소스를 따로 구분합니다. 같은 플레이어가 전에 사용하던 소스로 돌아오면 그 소스의 배속과 `R` 키 전환 기록을 복원합니다.
- 사용자가 패널이나 키보드로 바꾼 속도는 현재 탭과 현재 미디어 소스의 임시 상태로 보관됩니다. 새 소스에 처음 적용할 배속은 위 설정이 결정하고, 다른 소스와 다른 탭은 각자의 속도를 유지합니다. 탭을 닫으면 그 탭의 임시 상태도 제거됩니다. 미디어 소스를 구분할 때에는 서명과 토큰이 포함될 수 있는 전체 주소를 저장하지 않고 해시 식별자만 사용합니다.

### 속도와 앞뒤 이동 간격

- **속도 변경 간격**은 `S`와 `D` 키를 누를 때 한 번에 변하는 배속입니다. 0.01배부터 2배까지 설정할 수 있습니다.
- **앞뒤 이동 간격**은 `Z`와 `X` 키를 누를 때 이동하는 시간입니다. 1초부터 600초까지 설정할 수 있습니다.
- **R 키 기본 복원 배속**은 현재 미디어에 직전 배속 기록이 없을 때 `R` 키가 전환할 속도입니다. 초기값은 2.00배속이며 0.07배속부터 16배속까지 설정할 수 있습니다.

### 영상 위 속도 표시창

영상이 보이는 경우 현재 실제 재생 속도를 영상 위에 표시합니다.

- 기본 위치는 영상의 가운데 위입니다.
- 표시창을 마우스 왼쪽 버튼으로 끌어서 영상 안의 다른 위치로 옮길 수 있습니다.
- 이동한 위치는 저장되어 다른 페이지의 영상에도 같은 상대 위치로 적용됩니다.
- 패널의 **표시창을 가운데 위로 되돌리기**를 누르면 기본 위치로 복원됩니다.
- 오디오에는 영상 화면이 없으므로 표시창을 만들지 않지만 재생 속도와 키보드 조작은 동일하게 적용됩니다.

### 키보드 조작과 단축키 설정

입력란이나 편집 가능한 영역에 글을 쓰는 동안에는 미디어 단축키가 작동하지 않습니다. 기본 키는 다음과 같습니다.

| 기본 키 | 동작 |
|---|---|
| `S` | 설정한 간격만큼 느리게 재생 |
| `D` | 설정한 간격만큼 빠르게 재생 |
| `R` | 1.00배속과 직전 배속 사이를 전환하며, 직전 기록이 없으면 설정한 기본 복원 배속을 사용 |
| `Z` | 설정한 시간만큼 뒤로 이동 |
| `X` | 설정한 시간만큼 앞으로 이동 |
| `V` | 영상 위 속도 표시창 켜기 또는 끄기 |

패널의 **단축키 설정**에서 각 키 버튼을 누른 뒤 새 키를 입력하면 해당 기능의 단축키가 바뀝니다. 같은 키를 두 기능에 중복으로 지정할 수 없으며, **기본값 복원**을 누르면 `S`, `D`, `R`, `Z`, `X`, `V`로 되돌아갑니다. `Ctrl`, `Alt`, Windows 키와 함께 사용하는 조합은 지원하지 않습니다.

`R` 키로 3.00배속에서 1.00배속으로 전환한 경우, 같은 미디어에서 `R` 키를 다시 누르면 3.00배속으로 돌아갑니다. 새 미디어처럼 직전 배속 기록이 없는 상태에서 `R` 키를 누르면 패널의 **R 키 기본 복원 배속**을 사용하며, 처음 설정값은 2.00배속입니다.

현재 재생 중인 미디어를 우선하며, 재생 중인 항목이 없으면 마지막으로 마우스를 올린 미디어 또는 화면에서 가장 크게 보이는 영상을 대상으로 합니다. 영역 캡처나 페이지 요소 숨기기 도구가 열린 동안에는 미디어 단축키가 작동하지 않습니다.

### 로컬 파일

Chrome에서 직접 연 로컬 동영상과 오디오 파일에도 적용할 수 있습니다. `chrome://extensions`에서 확장 프로그램의 **세부정보**를 연 뒤 **파일 URL에 대한 액세스 허용**을 켜야 합니다.

### 동작 방식

사이트의 플레이어 버튼이나 주소를 추측해서 대신 누르지 않습니다. 브라우저가 제공하는 실제 `HTMLMediaElement.playbackRate`, `defaultPlaybackRate`와 `currentTime`만 사용합니다. 동적으로 추가된 노드를 확인하는 변경 감시 기능은 미디어 요소가 새로 생긴 경우에만 해당 요소를 등록하며, 페이지 전체를 반복해서 다시 검사하는 타이머는 사용하지 않습니다.

## 웹페이지 입력 제한 해제

패널에서 **웹페이지 입력 제한 해제**를 누르면 열 가지 토글이 드롭다운으로 열립니다. 드롭다운 맨 위의 **열 가지 기능 한 번에 설정** 토글을 사용하면 모두 한꺼번에 켜거나 끌 수 있습니다. 일부 기능만 켜진 경우에는 상위 토글이 중간 상태로 표시됩니다. 그 아래에서는 기능을 **마우스, 선택 및 복사**와 **링크 및 방문 기록**으로 나누어 표시하며, 각 기능도 계속 독립적으로 설정할 수 있습니다.

### 우클릭 메뉴 허용

웹사이트가 `contextmenu` 또는 오른쪽 마우스 버튼 이벤트를 막더라도 Chrome의 기본 우클릭 메뉴를 사용할 수 있게 합니다.

### 텍스트 드래그 및 선택 허용

웹사이트가 CSS 또는 선택 관련 이벤트로 막은 텍스트 선택을 다시 사용할 수 있게 합니다.

- 마우스로 텍스트를 드래그하여 선택할 수 있습니다.
- 일반적인 버튼, 입력란, 링크 및 페이지 안의 조작 요소에서는 불필요하게 마우스 동작을 가로채지 않습니다.

### 복사 차단 및 문구 변경 방지

선택한 내용에 대해 웹사이트가 `Ctrl + C` 또는 `copy` 이벤트를 가로채지 못하게 합니다. 따라서 웹사이트가 복사를 취소하거나 전혀 다른 문구로 바꾸는 일반적인 동작을 막고, Chrome의 기본 복사 동작을 그대로 사용합니다.

### 클립보드 덧붙이기 방지

복사할 때 선택한 텍스트를 확장 프로그램이 `text/plain` 형식으로 직접 지정합니다. 사이트 이름, 출처 주소 또는 안내 문구를 뒤에 덧붙이는 일반적인 복사 이벤트 처리를 막습니다.

이 기능을 켜면 선택한 텍스트를 일반 텍스트로 복사하므로, 글꼴, 링크 및 굵게 표시 같은 서식은 클립보드에 포함되지 않습니다.

### 이미지 드래그 허용

웹사이트가 이미지의 `draggable` 속성, 스타일 또는 드래그 이벤트로 막은 이미지 드래그를 다시 사용할 수 있게 합니다. 사용자가 이미지를 누를 때에만 잠시 드래그 속성을 보정하며, 마우스를 놓거나 드래그를 끝내면 원래 속성으로 되돌립니다.

### 가운데 버튼과 휠 클릭 허용

웹사이트가 마우스 가운데 버튼 이벤트를 막더라도 다음과 같은 Chrome 기본 동작을 유지합니다.

- 링크를 가운데 버튼으로 눌러 새 탭에서 열기
- 빈 영역에서 휠을 눌러 자동 스크롤 시작하기

이 토글은 마우스 휠을 회전하여 스크롤하는 동작을 바꾸지 않으며, 휠을 버튼처럼 누르는 동작만 대상으로 합니다.

### 자바스크립트 링크 새 탭 열기

일반 `<a>` 요소가 아니라 버튼이나 다른 요소에 주소를 넣어 둔 사이트에서도 다음 동작으로 새 탭을 열 수 있게 합니다.

- `Ctrl` 키를 누른 채 왼쪽 버튼으로 클릭
- 마우스 가운데 버튼으로 클릭
- 링크나 버튼을 우클릭한 뒤 **버튼 링크를 새 탭에서 열기** 선택

확장 프로그램은 클릭한 조작 요소 자체나 가장 가까운 명시적 버튼에서 `data-url`, `data-href`, `data-link-url`, `data-target-url`을 확인합니다. 인라인 코드에서는 문자열 리터럴로 직접 적힌 `window.open()` 또는 `location` 이동만 처리합니다. 폼 전송 주소, 숫자 식별자, 임의의 상위 요소, 난독화된 코드와 실행 중 변수는 주소로 추정하지 않습니다. 주소가 확실하지 않으면 새 탭을 열지 않습니다.

정상적인 `<a href>` 및 `<area href>` 링크는 확장 프로그램이 가로채거나 대신 열지 않습니다. Chrome의 원래 Ctrl+클릭과 가운데 클릭 동작을 그대로 사용하므로 주소 판별, 방문 기록 및 `:visited` 표시도 브라우저가 직접 처리합니다. 확장 프로그램은 링크 글자색을 임의로 변경하거나 별도의 방문 색상 기록을 저장하지 않습니다.

이 토글만 켠 경우에도 자바스크립트 버튼에서 확장 프로그램의 우클릭 메뉴를 열 수 있도록, 해당 상황에서는 사이트의 우클릭 차단 처리를 멈춥니다.

### 뒤로 가기 방해 차단

사이트가 현재 주소를 방문 기록에 반복해서 넣거나, 뒤로 이동한 직후 `history.forward()` 또는 `history.go(1)`을 실행하여 사용자를 다시 앞으로 보내는 일반적인 동작을 막습니다.

- 사용자가 뒤로 이동하여 `popstate`가 발생한 직후 약 1.4초 동안만 보호 창을 엽니다.
- 그 짧은 보호 창 안에서 현재 주소와 완전히 같은 주소를 다시 `pushState()`로 추가하는 요청을 차단합니다.
- 같은 보호 창 안에서 사이트가 `history.forward()` 또는 양수의 `history.go()`로 다시 앞으로 보내는 동작을 차단합니다.
- 평상시의 `pushState()`, 다른 주소 상태 추가, 뒤로 이동 및 앞으로 이동 요청은 바꾸지 않습니다.

이 기능은 토글을 켠 뒤 발생하는 방해 동작부터 막습니다. 이미 방문 기록에 들어간 항목을 임의로 삭제하지는 않습니다.

### 링크 주소 복사

토글을 켜면 웹페이지의 우클릭 메뉴에 **링크 주소 복사** 항목이 추가됩니다. 일반 `<a>` 링크에서는 Chrome이 우클릭 메뉴에 전달한 주소를 그대로 사용합니다. 버튼형 링크에서는 앞 절과 같은 보수적인 규칙으로 명시된 주소만 확인합니다. 서버에 접속하거나 경유 주소의 매개변수를 최종 주소라고 추정하여 풀지 않습니다.

1. 주소를 복사할 링크나 버튼에서 마우스 오른쪽 버튼을 누릅니다.
2. **링크 주소 복사**를 선택합니다.
3. 복사된 주소를 메모장이나 원하는 프로그램에 붙여넣습니다.

이 토글만 켠 경우에도 확장 프로그램의 우클릭 메뉴를 열 수 있도록 사이트의 우클릭 차단 처리를 해당 상황에서 멈춥니다.

### 사이트 자체 외부 링크 경고 건너뛰기

커뮤니티 사이트 등이 외부 링크를 열기 전에 표시하는 사이트 자체 확인 절차를 건너뜁니다. 기능은 처음에는 꺼져 있으며, 필요한 경우에만 켤 수 있습니다.

- `confirm()` 또는 `alert()`로 표시되는 외부 링크 안전 경고 문구를 자동으로 승인하거나 닫습니다.
- 실제 외부 링크를 누른 직후에 의미가 명확한 `dialog` 또는 `alertdialog` 경고 창이 나타난 경우에만 원래 누른 주소로 이동합니다.
- 주소 경로가 경고 또는 경유 화면임이 분명하고, 화면 문구도 외부 링크 경고로 확인되는 중간 페이지에서만 최종 주소로 이동합니다.
- 중간 경고 페이지를 건너뛸 때에는 `location.replace()`를 사용하여 뒤로 가기 목록에 경고 페이지가 남지 않도록 합니다.
- 일반 페이지의 `.popup`, `.layer`, `.modal` 같은 요소를 훑거나, **확인** 또는 **열기**라고 적힌 버튼을 임의로 누르지 않습니다.
- 숨은 입력란이나 관계없는 `data-*` 속성에서 목적지를 추측하지 않습니다.

이 기능은 웹사이트가 만든 확인 절차만 대상으로 합니다. Chrome의 안전 브라우징 경고, 인증서 오류, 다운로드 경고 및 `chrome://` 내부 화면은 변경하지 않습니다. 주소가 명확하지 않은 사용자 정의 경고 창은 잘못된 페이지로 이동하는 것을 막기 위해 자동으로 처리하지 않습니다.

### 가벼운 동작 방식

제한 해제 스크립트는 문서 변경 감시나 계속 실행되는 반복 타이머를 사용하지 않습니다. 사용자가 실제로 만든 이벤트만 처리하며 웹페이지가 합성한 마우스나 키보드 이벤트는 무시합니다. 설정된 동작과 관련된 마우스, 선택 또는 복사 이벤트가 발생했을 때만 사이트의 차단 처리를 멈춥니다. 외부 링크 경고 건너뛰기 기능도 명시적인 경고 전용 페이지가 열렸거나 실제 외부 링크를 누른 직후에만 잠시 확인합니다. 텍스트 선택에는 작은 스타일 요소 하나를 사용하며, 이미지 속성은 실제로 이미지를 누른 동안에만 보정합니다.

영역 캡처 도구가 열린 동안에는 제한 해제 기능이 잠시 물러나므로 기존처럼 마우스 오른쪽 버튼으로 영역 선택을 취소할 수 있습니다.

## 전체 페이지 화면 캡처

패널에서 **현재 페이지 전체 캡처** 버튼을 누르면 Chrome API가 알려 주는 현재 페이지의 전체 영역을 한 번에 PNG 파일로 저장합니다.

저장 위치:

```text
Downloads\full_page_screenshots
```

## 드래그 영역 화면 캡처

패널에서 **드래그하여 영역 캡처** 버튼을 누르면 패널이 닫히고 현재 페이지에 영역 선택 화면이 나타납니다.

- 마우스 왼쪽 버튼을 누른 채 직사각형 영역을 지정합니다.
- 화면 가장자리에 가까워지면 해당 방향으로 자동으로 스크롤됩니다.
- 모서리에 가까워지면 가로와 세로 방향으로 동시에 스크롤됩니다.
- 가장자리에 더 가까워질수록 스크롤 속도가 빨라집니다.
- `Esc` 키를 누르면 선택을 취소합니다.
- 마우스 버튼을 놓으면 선택한 영역만 PNG 파일로 저장합니다.

저장 위치:

```text
Downloads\selected_area_screenshots
```

## 클릭하여 페이지 요소 숨기기

패널의 **페이지 도구** 영역에서 **클릭하여 페이지 요소 숨기기**를 누른 뒤 다음 두 방식 중 하나를 선택합니다.

### 이번 페이지에서만 숨기기

현재 문서에서만 요소를 숨깁니다. 페이지를 새로 고치거나 다시 방문하면 원래대로 나타납니다.

### 이 사이트에 기억해서 숨기기

선택한 요소를 찾는 CSS 선택자를 현재 사이트의 출처 단위로 저장합니다. 같은 사이트를 다시 방문하면 저장된 요소를 자동으로 숨깁니다. 동적으로 나중에 만들어지는 같은 요소에도 저장된 CSS 규칙이 적용됩니다.

### 사용 방법

1. 요소를 숨기려는 웹페이지에서 확장 프로그램 패널을 엽니다.
2. **클릭하여 페이지 요소 숨기기**를 누릅니다.
3. **이번 페이지에서만 숨기기** 또는 **이 사이트에 기억해서 숨기기**를 선택합니다.
4. 패널이 닫히고 요소 숨기기 모드가 시작됩니다.
5. 마우스를 올리면 숨겨질 요소에 붉은 윤곽선과 요소 이름이 표시됩니다.
6. 마우스 왼쪽 버튼으로 클릭하면 해당 요소가 즉시 사라집니다.
7. 모드는 계속 유지되므로 다른 요소도 연속해서 클릭할 수 있습니다.
8. `Esc` 키를 누르거나 화면 위 안내 막대의 **종료** 버튼을 누르면 끝납니다.

사이트에 기억한 요소가 있을 때에는 요소 숨기기 드롭다운 아래쪽에 개수가 표시됩니다. **모두 복원**을 누르면 현재 사이트에서 기억한 규칙을 삭제하고 요소를 다시 표시합니다.

기억한 요소는 문서 전체를 계속 검사하는 반복 작업이나 변경 감시 기능으로 처리하지 않습니다. 저장된 선택자를 작은 CSS 규칙으로 적용하므로, 규칙이 없는 사이트에서는 별도의 페이지 변경 감시 작업이 실행되지 않습니다.

## 열린 탭 URL 복사

1. 패널에서 **열린 탭 URL 복사**를 누릅니다.
2. 현재 Chrome 창에 열려 있는 탭 목록에서 원하는 탭을 선택합니다.
3. **선택한 URL 복사** 버튼을 누릅니다.
4. 선택한 탭의 URL이 탭 표시 순서대로 클립보드에 복사됩니다.

복사되는 내용은 다음과 같이 URL 하나가 한 줄씩 배치됩니다.

```text
https://example.com/first
https://example.com/second
https://example.com/third
```

목록 안에서 **모두 선택**, **선택 해제**, **새로고침**을 사용할 수 있습니다. 목록에는 현재 활성화된 탭을 알아볼 수 있도록 **현재** 표시가 나타납니다.

## 권한

- `storage`: 단축키, ChatGPT 대화 및 입력란 너비, 유튜브 자막 출력 형식과 선호 언어, 미디어 공통 설정과 탭별 임시 재생 속도, 표시창 위치, 웹페이지 제한 해제 설정 및 사이트별 요소 숨기기 규칙을 저장합니다.
- `activeTab`: 사용자가 패널을 연 현재 탭에서 캡처 기능을 시작합니다.
- `scripting`: 영역 캡처 선택 화면과 페이지 요소 숨기기 화면을 현재 탭에 일시적으로 삽입하고, 선택한 유튜브 탭에서 자막 정보를 읽는 작업을 실행합니다.
- `debugger`: Chrome의 페이지 캡처 명령을 사용합니다.
- `downloads`: PNG 화면 캡처와 유튜브 자막 텍스트 파일을 다운로드 폴더에 저장합니다.
- `tabs`: 현재 Chrome 창에 열려 있는 탭의 이름과 URL을 패널에 표시하고, 탭별 미디어 속도 상태와 선택한 유튜브 탭을 구분합니다.
- `clipboardWrite`: 사용자가 복사 버튼이나 링크 주소 복사 메뉴를 사용할 때 URL을 클립보드에 넣습니다.
- `contextMenus`: 우클릭 메뉴에 **버튼 링크를 새 탭에서 열기**와 **링크 주소 복사** 항목을 추가합니다.
- HTTP 및 HTTPS 사이트 접근: 웹페이지 입력 제한 해제, 기억한 요소 숨김, 미디어 기능을 적용하고, 해당 프레임의 뒤로 가기 보호와 외부 링크 경고 설정을 페이지 실행 환경에 직접 전달합니다. 선택한 다른 유튜브 탭의 자막도 이 권한 범위에서 읽습니다.
- 로컬 파일 접근: 사용자가 Chrome 세부정보에서 별도로 허용한 경우에만 `file://`로 연 동영상과 오디오에 미디어 속도 조절 스크립트를 불러옵니다.

유튜브 자막 내용은 사용자가 복사 또는 저장 버튼을 누를 때 선택한 유튜브 탭 안에서만 읽으며 외부 서버로 보내지 않습니다. 탭 이름과 URL은 패널 안에서 선택 목록을 만드는 데에만 사용됩니다. 확장 프로그램은 입력 내용, 대화 내용, 탭 목록 또는 복사한 URL을 외부 서버로 보내지 않습니다. 링크 방문 여부나 링크 색상을 위한 별도 기록도 저장하지 않습니다.

## 제한 사항

- 유튜브 자막 추출은 현재 영상에서 유튜브가 제공하는 자막 트랙을 대상으로 합니다. 자막이 없는 영상, 아직 자막 처리가 끝나지 않은 영상, 일부 실시간 방송 또는 계정과 지역 조건 때문에 대본 자체가 제공되지 않는 영상에서는 사용할 수 없습니다.
- 자동 번역 언어는 유튜브 플레이어가 현재 영상에 대해 제공한 목록만 표시합니다. 자동 번역 결과의 정확도와 제공 여부는 유튜브에 따라 달라집니다.
- 유튜브 자막 탭 목록은 확장 프로그램 패널을 연 Chrome 창의 탭만 표시합니다. 절전 상태이거나 플레이어 정보가 메모리에서 내려간 탭은 자막 목록을 불러오지 못할 수 있으며, 해당 탭을 한 번 연 뒤 다시 시도하면 복구될 수 있습니다.

- 미디어 속도 조절은 표준 `<video>`와 `<audio>` 요소를 대상으로 합니다. 사이트가 별도의 비표준 플레이어를 사용하거나 재생 속도를 자체적으로 제한하면 일부 범위가 적용되지 않을 수 있습니다.
- 매우 느리거나 빠른 속도에서는 Chrome 또는 사이트가 소리를 음소거하거나 음질을 다르게 처리할 수 있습니다.
- 영상 요소 자체가 브라우저의 전체 화면 요소가 되는 특수한 전체 화면 방식에서는 확장 프로그램 표시창이 보이지 않을 수 있습니다. 일반적인 플레이어 컨테이너 전체 화면에서는 표시창 위치를 다시 계산합니다.
- 로컬 파일에는 사용자가 확장 프로그램 세부정보에서 **파일 URL에 대한 액세스 허용**을 켠 경우에만 적용됩니다.
- `chrome://`으로 시작하는 Chrome 내부 페이지와 Chrome 웹 스토어에는 웹페이지 제한 해제 기능이 적용되지 않습니다.
- 웹사이트가 투명한 요소를 이미지 위에 덮거나 브라우저 정책 수준에서 기능을 막은 경우에는 이미지 드래그를 복원하지 못할 수 있습니다.
- 닫힌 Shadow DOM 안에서 CSS만으로 막은 텍스트 선택은 복원하지 못할 수 있습니다.
- 복사 동작과 무관하게 별도의 클립보드 쓰기 권한으로 나중에 클립보드를 다시 덮어쓰는 웹 애플리케이션까지 항상 차단할 수 있는 것은 아닙니다.
- 자바스크립트 링크의 주소가 난독화된 코드나 실행 중인 비공개 변수 안에만 존재하고 HTML 속성이나 클릭 코드에 나타나지 않으면 새 탭 열기와 링크 주소 복사 기능이 주소를 알아내지 못할 수 있습니다.
- 짧은 주소나 경유 주소의 최종 목적지는 서버 응답 없이는 확인할 수 있으므로 확장 프로그램이 추정하지 않습니다. 우클릭 메뉴에서는 페이지에 명시된 원래 주소를 복사합니다.
- 뒤로 가기 방해 차단은 실제 뒤로 이동 직후의 짧은 보호 창에서만 작동합니다. 그래도 특수한 탐색 방식을 쓰는 사이트에서 문제가 생기면 이 토글만 끌 수 있습니다.
- 사이트 자체 외부 링크 경고 건너뛰기를 켜면 사이트가 제공하는 위험 안내를 보지 않고 이동할 수 있으므로, 신뢰하는 링크에만 사용하는 것이 좋습니다. 일반 페이지의 버튼을 자동으로 누르지는 않으며, 대상 주소나 경고 화면이 명확하지 않으면 자동으로 건너뛰지 않습니다.
- 개발자 도구 또는 다른 확장 프로그램이 같은 탭의 디버거를 사용하고 있으면 화면 캡처가 실패할 수 있습니다.
- 영역 자동 스크롤은 웹페이지 전체의 기본 스크롤을 대상으로 하며, 페이지 안의 별도 스크롤 상자까지 자동으로 움직이지는 않습니다.
- 열린 탭 URL 목록은 확장 프로그램 패널을 연 Chrome 창의 탭만 표시합니다.
- 사이트에 기억하는 요소 숨기기는 현재 사이트의 출처 단위로 적용됩니다. 위치 순서 선택자는 저장하지 않고 고유한 식별자나 안정적인 속성으로 다시 찾을 수 있는 요소만 저장합니다. 사이트가 해당 식별자를 다른 요소에 재사용하면 그 요소가 숨겨질 가능성은 남아 있습니다.
- 닫힌 Shadow DOM 안의 요소는 재방문 때 사용할 CSS 선택자를 만들 수 없으므로 **이번 페이지에서만 숨기기** 방식만 사용할 수 있습니다.



## 버전 1.26.0 변경 사항

- 미디어의 현재 재생 속도를 `chrome.storage.local`의 공통 값으로 저장하던 방식을 제거했습니다.
- 각 탭의 재생 속도를 탭 식별자별 임시 상태로 분리하여 한 탭에서 바꾼 배속이 다른 탭으로 전달되지 않게 했습니다.
- 같은 탭에 여러 동영상이나 오디오가 있어도 미디어 요소와 소스별로 배속과 `R` 키 전환 기록을 분리했습니다.
- 패널의 재생 속도 슬라이더는 현재 재생 중이거나 마지막으로 마우스를 올린 미디어 소스 하나만 읽고 변경합니다.
- 현재 Chrome 창에 열린 유튜브 일반 영상, Shorts 및 라이브 영상 탭을 선택하는 목록을 추가했습니다.
- 선택한 탭마다 원본 자막과 유튜브 자동 번역 언어를 별도로 설정할 수 있게 했습니다.
- 선택한 여러 탭의 자막을 탭 순서대로 하나의 클립보드 내용으로 합치는 기능을 추가했습니다.
- 선택한 여러 탭의 자막을 하나의 텍스트 파일로 저장하거나, 탭별 개별 파일로 일괄 저장하는 기능을 추가했습니다.
- 한 탭의 자막 추출이 실패해도 나머지 탭의 작업을 계속하고, 탭별 오류를 목록에 표시하도록 했습니다.
- 현재 활성 탭이 아닌 선택된 유튜브 탭에서도 자막을 추출하기 위해 유튜브 사이트 접근 권한을 명시적으로 추가했습니다.

## 버전 1.25.0 변경 사항

- 유튜브 일반 영상과 Shorts의 전체 자막을 한 번에 복사하는 기능을 추가했습니다.
- 원본 자막 트랙과 유튜브 자동 번역 언어를 선택할 수 있게 했습니다.
- 영상 제목과 재생 시간의 포함 여부 및 문장 사이의 빈 줄 개수를 설정할 수 있게 했습니다.
- 정리한 자막을 `다운로드\youtube_transcripts` 폴더에 UTF-8 텍스트 파일로 저장할 수 있게 했습니다.
- 같은 영상과 언어 조합은 패널이 열려 있는 동안 다시 사용하여 출력 형식을 바꿀 때 자막을 반복해서 요청하지 않습니다.
- 일반 영상과 Shorts에서 현재 재생 중인 플레이어를 우선하여 자막 정보를 확인합니다.
- 새로운 Chrome 권한은 추가하지 않았습니다.

## 버전 1.24.0 변경 사항

- 이전 배속 기록이 없는 미디어에서 `R` 키가 사용할 기본 복원 배속을 추가했습니다.
- 기본 복원 배속의 초기값은 2.00배속이며, 패널에서 0.07배속부터 16배속까지 0.01배 단위로 설정할 수 있습니다.
- 미디어가 일시적으로 0 또는 유효하지 않은 속도를 보고할 때 이를 최소값인 0.07배속으로 기억하지 않도록 수정했습니다.
- 이전 배속 기록이 없더라도 `R` 단축키 입력을 확장 프로그램이 처리하므로, 같은 키를 사용하는 웹사이트 기능이 뜻하지 않게 실행되지 않습니다.
- 기존 기능과 권한은 그대로 유지했습니다.

## 버전 1.23.0 변경 사항

- 영상 위 속도 표시창의 기본 위치를 왼쪽 위에서 가운데 위로 옮겼습니다.
- 기존의 정확한 왼쪽 위 기본 위치를 사용하던 설치는 새 기본 위치로 자동 전환하며, 사용자가 직접 옮긴 다른 위치는 유지합니다.
- **새 미디어에 마지막 속도 유지** 토글을 추가했습니다. 끄면 새 동영상과 오디오는 1.00배속으로 시작하고, 켜면 마지막 설정값을 이어서 적용합니다.
- `R` 단축키를 1.00배속과 직전 배속 사이를 오가는 방식으로 변경했습니다.
- 느리게, 빠르게, 배속 전환, 뒤로 이동, 앞으로 이동 및 표시창 기능의 키를 패널에서 각각 지정할 수 있게 했습니다.
- 같은 키의 중복 지정을 막고, 여섯 가지 키를 한 번에 기본값으로 되돌리는 버튼을 추가했습니다.
- 기존 ChatGPT 단축키와 너비, 화면 캡처, 페이지 요소 숨기기, 탭 URL 복사 및 웹페이지 제한 해제 기능은 그대로 유지했습니다.

## 버전 1.22.0 변경 사항

- HTML5 동영상과 오디오의 재생 속도 조절 기능을 추가했습니다.
- 0.07배속부터 16배속까지 0.01배 단위로 설정할 수 있습니다.
- 키보드 속도 변경 간격과 앞뒤 이동 시간을 각각 설정할 수 있습니다.
- `S`, `D`, `R`, `Z`, `X`, `V` 키를 이용한 빠른 조작을 추가했습니다.
- 영상 위에 실제 현재 속도를 표시하고, 표시창을 드래그하여 옮길 수 있게 했습니다.
- 동적으로 생성되는 미디어 요소와 일반 프레임 안의 미디어에도 적용되도록 구성했습니다.
- Chrome에서 별도로 허용한 경우 로컬 동영상과 오디오 파일에도 적용됩니다.
- 기존 설치에서 영상 속도가 갑자기 바뀌지 않도록 미디어 기능은 처음에는 꺼져 있습니다.
- 기존 ChatGPT 단축키와 너비, 화면 캡처, 페이지 요소 숨기기, 탭 URL 복사 및 웹페이지 제한 해제 기능은 그대로 유지했습니다.
