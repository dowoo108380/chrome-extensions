파일 포함 이미지 만들기

표지 이미지 뒤에 ZIP 구조를 붙여, 이미지로도 열리고 압축 파일로도 읽을 수 있는 하나의 파일을 만듭니다.

암호화 기능이 아닙니다. 결과 파일 안의 원본 파일은 ZIP 호환 압축 프로그램으로 쉽게 꺼낼 수 있습니다. 비밀번호, 인증서, 개인 문서처럼 보호가 필요한 자료를 숨기는 용도로 사용하지 마십시오.

결과 파일 만들기

파일 이름에는 영문, 숫자와 밑줄만 사용할 수 있습니다. 실제 확장자는 표지 이미지 형식에 맞게 자동으로 정해집니다.

파일을 확인하고 있습니다.

표지 이미지와 담을 파일을 준비하십시오.

이미지로 보기

생성된 파일은 표지 이미지와 같은 확장자로 저장됩니다. 일반 이미지 뷰어나 웹페이지에서 열면 선택한 표지만 표시됩니다.

파일 꺼내기

결과 파일의 복사본을 만든 뒤 확장자를 .zip으로 바꾸거나, 7-Zip 같은 ZIP 호환 프로그램에서 직접 열어 파일을 추출하십시오.

크기와 처리 방식

파일은 무압축 ZIP 구조로 담깁니다. 결과 크기는 표지 이미지와 원본 파일의 합계에 작은 ZIP 헤더가 더해진 정도이며, 생성 전에 각 파일의 CRC32를 실제로 계산합니다.

개인정보

모든 처리는 이 확장 프로그램 페이지 안에서 이루어집니다. 선택한 파일은 외부 서버로 전송하지 않습니다.
