# YouTube 선호 화질 대기 오류 수정 — 1.77.3

2026-09-29 사용 중인 실제 Chrome의 YouTube 시청 페이지와 수정 전 코드를 비교했습니다. 본 영상의 톱니바퀴 버튼은 존재하고 활성화되어 있었으나 `aria-label="null"`, `data-tooltip-title="null"`이었습니다. 기존 `gearOf()`는 설명이 `설정` 또는 `Settings`에 일치하는 버튼만 인정해서 `확인 가능한 YouTube 설정 버튼을 기다립니다.` 상태에서 진행하지 못했습니다.

## 원인과 이전 검증의 누락

저장된 선호 해상도가 없어진 문제가 아니라 저장 이후 플레이어에서 설정 버튼을 찾는 단계의 실패였습니다. 기존 테스트는 `aria-label="설정"`인 버튼을 사용했으며, 팝업 검사와 플레이어 검사를 각각 모의 Chrome API로 수행했습니다. 실제 페이지의 설명 누락과 실제 팝업부터 콘텐츠 스크립트까지 연결되는 경로를 확인하지 못한 검증 공백입니다.

실제 메뉴의 `Preferred Premium`, `Preferred Quality` 행은 이 프로젝트가 생성하지 않습니다. 관찰된 행은 `ythdp-icon` 클래스를 포함하고 네이티브 `화질` 행과도 별도였습니다. 이 확장의 저장소와 연동되는 항목으로 간주하지 않으며, 해당 행을 변경해서 문제를 우회하지 않습니다. 어떤 외부 프로그램이 행을 만들었는지는 이번 검사에서 특정하지 않았습니다.

## 수정

- 본 영상 플레이어 안의 고유하고 표시된 네이티브 `button.ytp-settings-button`을 식별합니다. 비어 있거나 `null`인 설명 때문에 제외하지 않습니다.
- 버튼을 연 이후에도 실제 `화질`/`Quality` 메뉴, 해상도 목록, `aria-checked` 선택 상태를 확인합니다. 중복 버튼·모호한 메뉴·선택 실패를 성공으로 표시하지 않습니다.
- 버튼 또는 버튼을 감싼 조작부의 표시·활성 상태가 바뀌면 다시 확인합니다. `disabled`, `inert`, `aria-hidden` 변화도 포함합니다. 자막·시간 표시 변화로 화질을 계속 강제하지 않습니다.
- 권한, 저장 키, 수동 선택 유지 정책, Premium 이용 가능 판정은 변경하지 않았습니다. 현재 영상에서 수동 선택했다면 팝업의 **이 영상의 자동 선택 다시 시작**으로 재개할 수 있습니다.

## 재현과 검증 범위

1. 수정 전 배포 코드에 `aria-label="null"` 사례를 넣어 사용자가 보고한 대기 상태를 재현했습니다. 결과는 `verification/quality-fix-1.77.3/before.json`입니다.
2. 수정 후 화질 구성요소 50건, 팝업 9건, Node 83건을 통과했습니다. 빈 설명, 설명 없음, 지연된 표시·활성화, 버튼 중복, 수동 선택 유지, 메뉴 복원, 다음 영상과 설정 변경의 경합 등을 포함합니다.
3. 임시 Chrome 프로필에 실제 확장을 설치한 통합 검사 9건을 추가했습니다. 실제 도구 모음 팝업에 신뢰된 마우스·키보드 입력을 보내 설정을 저장하고, 실제 `chrome.storage`와 `chrome.tabs.sendMessage`를 거쳐 콘텐츠 스크립트의 적용을 확인합니다. 패널에서 4320p 선택 → 현재 영상 적용 → 다음 영상에서 제공되는 2160p로 대체 → 수동 선택 유지 → 패널에서 720p 저장·다시 시작 → 다음 영상·새 문서에서 720p 적용 → 팝업 재개방 시 설정 유지 경로입니다.
4. 통합 검사에서 YouTube 메뉴와 영상은 로컬 fixture입니다. 실제 관찰한 버튼·메뉴 구조를 반영했지만 실서비스의 스트리밍·Premium 재생 권한·다른 확장의 동작 전체를 검증한 것은 아닙니다. 메뉴에서 확인한 선택과 디코딩 크기를 구분하는지도 검사합니다.
5. 배포 ZIP을 새로 풀어 설치하는 검사에도 이 통합 테스트를 포함했습니다. 실제 팝업 크기 검사에서 사용하던 CDP 팝업 연결 도우미는 공통 파일로 이동해 중복 구현을 없앴습니다.

## 현재 사용자 브라우저에 적용

워크스페이스 파일과 빌드 산출물은 1.77.3으로 갱신했습니다. 연결된 사용자 Chrome의 `chrome://extensions` 접근은 브라우저 도구의 보안 정책에서 차단되었습니다. 이를 우회하지 않았으며, 사용 중인 확장의 다시 로드와 수정 후 실서비스 검증은 완료했다고 주장하지 않습니다.

워크스페이스를 설치 경로로 사용 중이면 확장 관리 화면에서 해당 확장을 **다시 로드**한 뒤 YouTube 페이지를 **F5**로 새로 고칩니다. 별도 설치 폴더라면 1.77.3 ZIP의 파일을 그 폴더에 먼저 반영합니다. 확장 아이콘 → YouTube에서 자동 선택을 켜고 선호 해상도를 저장한 뒤, 현재 영상과 다음 영상의 **현재 상태 확인** 결과를 확인합니다.

검증 파일과 브라우저에서 관찰한 제한된 DOM 정보는 `verification/quality-fix-1.77.3`에 보관합니다. 로그인 정보·쿠키·탐색 기록은 수집하지 않았습니다.
